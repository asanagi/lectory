Lectory · Design System Exploration

Three integrated design themes for the marketing site

Grounded in the product and web requirements docs and the existing navy/teal brandmark, each theme below is a complete, self-consistent system — color, type, live components, and a mini hero — not a mood board. All three stay within functional B2B SaaS conventions: no parallax, no scroll-jacking, no auto-playing video. Motion is limited to ordinary hover/focus feedback and one subtle "live" status pulse in Theme 2, which speaks directly to the real-time positioning wedge. Hover and click the components below — they're live CSS, not screenshots.

Reading this before locking tokens

All three themes share one brand navy (#1E3A8A) and one brand teal (#14B8A6) — only the surrounding neutrals, type pairing, and how hard teal is pushed change. That's deliberate: the marketing site can carry one theme end-to-end, or run Executive Trust on buyer-facing pages (home, security, pricing) while Practice Studio takes the solutions pages, without reading as two different products. Runtime Signal is the outlier — a dark, technical mode purpose-built for /why-real-time and platform-architecture content — and is the one most worth a stakeholder gut-check before it goes further than a page or two.

Every button state above is real CSS (:hover, :active, :focus-visible, :disabled), and every swatch copies its hex on click. Nothing on this page scroll-jacks, autoplays, or hijacks the wheel event — all motion is a hover response or (Theme 2 only) a slow, reduced-motion-aware status pulse.
